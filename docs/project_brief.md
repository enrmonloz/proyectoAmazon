# Project brief

## Context
SVQ1 (Dos Hermanas) and DQA4 (Sevilla) operate as separate facilities.
The case studies whether unifying them into one center is viable.

## Decision focus
Compare two main options: expand SVQ1 or build an intermediate location.
The analysis must balance routes, economics, workforce, risks, and schedule.

## Scope
This is an academic viability tool based on the enunciado data.
It is not a prediction of real Amazon operations.
