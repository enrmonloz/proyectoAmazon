# Pytest hardening skill

- Review existing tests in tests/ before adding new ones.
- Add small, deterministic tests that validate compatibility.
- Prioritize edge cases for demand, split delivery, and location.
- Avoid fragile tests that depend on Streamlit visual order.
- Do not change business logic just to satisfy tests without justification.
