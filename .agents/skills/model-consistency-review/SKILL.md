# Model consistency review skill

- Compare changes against docs/assumptions.md.
- Look for contradictions between routing, location, and economics.
- Ensure location does not decide more than it should.
- Check that UI changes do not hide key assumptions.
- Note any mismatch with the future scenario model in docs/scenario_model.md.
